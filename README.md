## The pitch

> The Parachute Toaster launches every slice under a tiny parachute so it can never land butter-side down, then salutes as it drifts gently onto your plate.

One sentence, 154 characters — a ridiculous invention fixing the tiny
everyday annoyance of toast always landing butter-side down.

## How it works

`main.py` writes the pitch to `/output/entry.txt` (the artifact the
bounty harness grades: UTF-8 text, 1–220 characters) and prints the
exact same sentence to stdout.

```sh
python3 main.py
```
